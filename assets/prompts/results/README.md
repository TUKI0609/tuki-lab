# TUKI PROMPT BOX · 미리보기 이미지 (병합 전)

이 폴더는 TUKI PROMPT BOX의 프롬프트 카드 이미지 3개를 놓는 위치입니다.

| 업로드할 파일 | 연결할 카드 | 정확한 설명 |
| --- | --- | --- |
| `pixel-guild-card-result.webp` | 도트 RPG 탐험가 등록증 | 2026-10-14에 이미지 생성 AI로 새로 만든 **샘플 등록증**. 실제 사용자 프로필을 적용한 결과는 아님 |
| `bookmark-x-post-result.webp` | 북마크형 X 정보 글 | AI로 제작한 **게시물 구성 목업**. 실제 X에 게시하거나 해당 텍스트를 검증한 결과는 아님 |
| `mobile-game-screen-example.webp` | PC·모바일 화면 수정 | AI로 만든 **문제·수정 방향 비교 콘셉트**. 실제 소스코드 변경/검증된 게임 스크린샷은 아님 |

원본 ChatGPT 이미지 3장을 각각 950×713 WebP로 웹 최적화해 둔 파일을 이 폴더에 업로드하면 됩니다.

**중요:** 이미지 3개가 저장소에 반영됐는지 확인하기 전에는 `content/prompts.json`의 기존 참조를 제거하거나 실제 결과물로 교체했다고 표시하지 않습니다. 업로드 완료 후 같은 Draft PR에서 프롬프트 카드의 이미지 경로·캡션을 변경하고 모바일/이미지 로딩/복사 테스트를 다시 수행합니다.

다른 카드 2개:
- 게임 업데이트 쇼츠: 기존 검증된 W41 공개 영상 썸네일 유지.
- 10초 캐릭터 영상: 실제 영상 결과물 확보 전까지 AEVOWAKE 참고 이미지로 명시.
