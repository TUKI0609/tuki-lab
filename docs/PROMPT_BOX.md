# TUKI PROMPT BOX · 공개용 프롬프트 보관함

## 목적
TUKI LAB은 제작/수정 기록이고, TUKI PROMPT BOX는 방문자가 이미지·영상·글쓰기·게임 제작용 프롬프트를 **찾고, 읽고, 복사하는** 별도의 도구형 공간입니다.

주소: `/prompts/`. 전용 상단 내비게이션 탭 '프롬프트'와 홈 바로가기로 진입합니다. 카드 고유 주소는 `/prompts/#<prompt-id>`이며 X 게시물에도 이 주소를 공유할 수 있습니다.

## 데이터 모델
프롬프트 항목은 `content/prompts.json`의 `prompts` 배열에 저장합니다.
- `id`: URL에 노출되는 고유 slug. 한 번 공개한 뒤 함부로 변경하지 마세요.
- `category`: `image`, `video`, `writing`, `game`.
- `title`, `summary`, `tool`, `tags`: 목록 및 검색 화면.
- `prompt`: 복사 버튼이 **전부 복사**하는 원본 텍스트. 대괄호 `[교체할 항목]`은 사용자가 바꿉니다.
- `preview`: `type` (`image`|`text`), `src` 또는 `lines`, `label`, `note`; 선택적으로 `sourceUrl`/`sourceLabel` (본인 공개 YouTube 작품만).
- 프롬프트의 내용과 이미지 출처 모두 외부 사용자에게 공개 가능한지 **발행 전 검토**해야 합니다.

## 미리보기의 진실성
현재 초안은 5개의 공개용 템플릿을 **새로 정리한 것**입니다. 이전 개인 프롬프트 원문을 그대로 복원했다고 주장하지 않습니다.

- 길드 등록증/캐릭터 영상/게임 점검 카드의 이미지는 기존 TUKI WORLD의 **참고용 프로젝트 아트**입니다. 해당 프롬프트로 만든 실제 결과물이라고 표현하지 않습니다.
- LUTRATIDE 게임 영상 카드는 실제 공개 제작 쇼츠의 **썸네일**을 사용합니다. 프롬프트와 정확히 동일한 방식으로 만든 영상이라고 주장하지 않습니다.
- X 글 템플릿은 **구조 예시**를 텍스트 카드로 표현합니다. 실제 게시물 캡처가 아닙니다.
- 향후 본인의 원본 생성 결과 이미지/영상 파일을 확보하고 출처/사용 허락을 검토한 뒤 교체하면 실제 결과 미리보기로 발전시킬 수 있습니다.
- 외부 작가/서비스의 이미지·영상은 사용권을 확인하지 않고 복제하거나 사이트에 업로드하지 마세요.

## QA
1. `node --test tests/*.test.mjs`
2. `node scripts/build-lab-search-pages.mjs --check`
3. `node --check js/prompts.js`
4. 브라우저로 `/prompts/`를 열어 필터 5개, 제목·태그 검색, 전부 복사 및 복사 성공/실패 안내, 프롬프트 펼치기, 고유 해시 링크, 이미지 실제 로딩을 검증합니다.
5. 390px 모바일 화면에서 다섯 내비게이션 탭에 접근하고 페이지가 가로로 잘리지 않는지 확인합니다.
6. 기존 `js/core.js`의 개인정보 동의 및 GA4 측정 로직을 재사용하며 **동의 없는 추적 기능은 추가하지 않습니다**.

## 공개 정책
기존 TUKI WORLD 승인 정책을 유지합니다. 새 프롬프트는 원문과 예시 이미지의 출처, 용도, 누락된 입력 변수, 법적 주의사항을 검토한 후 별도 PR로 올립니다. 배포는 PR 테스트가 통과해도 사용자 **최종 승인 후** 진행합니다. RSS/YouTube/X 자동수집은 이 기능에서 변경하지 않습니다.


## RPG 탐험가 등록증 다국어 빌더 (2026-10-14)
- 대상 카드: 기존 URL /prompts/#pixel-guild-card (slug 변경 없음).
- UI 언어: 브라우저의 선호 언어 중 ko, en, ja 첫 일치값 선택. 그 외는 영어. 카드 내부 한국어 / English / 日本語 선택기로 즉시 변경. 사이트 전체 js/core.js의 한국어/영어 전환은 변경하지 않음.
- X 핸들: @ 포함 또는 제외하고 입력 가능하며, 복사본에는 유효한 1~15자의 영문/숫자/밑줄 핸들을 @와 함께 넣음. 사용자 핸들을 네트워크 요청·저장소·URL에 보내거나 저장하지 않음. 로컬 브라우저의 메모리 상태에만 유지하며 새로고침 시 소멸.
- 이미지: TUKI WORLD는 업로드 기능을 제공하지 않음. 이용자가 생성 AI 채팅에 직접 프로필 이미지 1장을 첨부할 때만 AI가 참고.
- 생성 규칙: content/prompts.json의 공통 영문 본문 1개, 사용자 입력 X HANDLE/CARD LANGUAGE는 js/guild-card.mjs에서 빌드. X 게시물 접근 가능 여부는 AI 도구에 따라 달라짐. 미검증 시 게시물/팔로워/성과를 지어내지 않고 이미지 중심 창작.
- 카드 언어와 X 게시물 언어는 독립. 자동 길드명, 클래스, 칭호, 3개 스킬, 통일된 2:3 픽셀 UI 및 각 언어 표기 명령을 포함.
- 미리보기는 여전히 CRYPTO SAGA의 참고용 콘셉트 이미지. 이 버전 프롬프트에서 생성된 결과물로 오인시키지 않음.
- 검증: 기존 node --test tests/*.test.mjs, 브라우저 QA, 390px 모바일 화면. UI 한국어/영어/일본어 문구, 언어별 생성 프롬프트, 핸들 유효성, X 활동 미확인 문구, 실제 복사 내용 확인.
- 이 PR은 다국어 RPG 카드 1개만 개편. 전체 PROMPT BOX 카탈로그의 세 언어 번역은 별도 작업으로 분리.
